# HiPepTox baselines

This release includes ToxiPep, ToxTeller, ToxMSRC, PLPTP, CAPTP, tAMPer, ToxGIN, ToxinPred3, PeptiTox, and StrucToxNet.

The [registry](registry.json) lists model directories and training/evaluation entry points. See [PREPARATION.md](PREPARATION.md) for datasets, external resources, and environment requirements.

Original source code, READMEs, and available license files are retained. Historical artifacts mentioned in upstream documentation are not bundled with this release.

The StrucToxNet model, CSV interfaces, preprocessing scripts, and static normalization arrays are documented in [structoxnet/README.md](structoxnet/README.md).
