# HiPepTox 基线代码

精简版包含 ToxiPep、ToxTeller、ToxMSRC、PLPTP、CAPTP、tAMPer、ToxGIN、ToxinPred3、PeptiTox 和 StrucToxNet。
模型目录和训练/评估入口见 registry.json；运行前的数据与外部资源准备见 [PREPARATION.md](PREPARATION.md)。
各方法的原始 README、许可文件与源代码保留；原文涉及的历史产物路径不属于本精简版。

StrucToxNet 的模型、CSV 接口、预处理及静态归一化数组见 [structoxnet/README.md](structoxnet/README.md)。
